# 词汇闪测 (Vocab Flash Test) v0.1.0

一个基于Flutter开发的智能英语词汇学习应用，采用间隔重复系统(SRS)算法，帮助用户高效记忆英语单词。

## 🆕 v0.1.0 版本特性

### 🎯 核心功能
- ✅ **智能测试系统**: 基于SRS算法的自适应词汇测试
- ✅ **多级别词汇库**: 支持A1-C2级别的Oxford 3000核心词汇
- ✅ **个性化学习**: 根据答题表现自动调整难度和复习频率
- ✅ **不熟悉单词管理**: 自动标记错误单词，支持针对性复习

### 🔧 用户体验优化
- ✅ **应用生命周期管理**: 后台暂停/恢复功能，避免误操作
- ✅ **智能答案显示时间**: 正确答案250ms，错误答案1000ms停留时间
- ✅ **选项状态重置**: 修复选项高亮延续问题，确保每题开始时无选中状态
- ✅ **自动错词收集**: 测试中答错或超时的单词自动加入不熟悉词库

## 🧮 SRS算法详解

### 核心原理
应用采用改进的SRS(Spaced Repetition System)算法，基于以下要素：

- **稳定度(Stability)**: 表示记忆保持的时间长度
- **难度(Difficulty)**: 表示单词的学习难度
- **质量分数(Quality)**: 基于答题结果和反应时间的综合评分

### 质量分数计算
```
q = 1: 错误或超时
q = 3: 正确但反应时间 > 80%时限 (慢对)
q = 4: 正确且反应时间适中 (普通对)  
q = 5: 正确且反应时间 ≤ 50%时限 (快对)
```

### 参数更新公式
```
难度更新: D' = clip(D + 0.1 - (5-q) * (0.08 + (5-q) * 0.02), 1.2, 3.0)
稳定度更新: 
  - 正确时: S' = S * (1 + α * (5-q))
  - 错误时: S' = β (重置)
复习间隔: I = S * γ
```
