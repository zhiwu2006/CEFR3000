# 词汇闪卡 📚

一个智能的英语单词学习应用，采用闪卡记忆法帮助用户高效学习词汇。

## 应用特色 ✨

- **智能闪卡系统**: 基于记忆曲线的单词复习机制
- **多级难度**: 支持A1-C2等级的词汇学习
- **语音朗读**: 内置TTS功能，帮助正确发音
- **进度追踪**: 详细的学习进度和统计分析
- **离线学习**: 支持离线使用，随时随地学习
- **现代UI**: 简洁美观的Material Design界面

## 功能介绍 🎯

### 主要功能
- 📖 **单词测试**: 多选题形式的单词测试
- 🔄 **智能复习**: 根据记忆曲线安排复习
- 📊 **学习统计**: 详细的学习数据分析
- 🎵 **语音朗读**: 标准英语发音
- ⏱️ **计时测试**: 限时答题提高反应速度
- 🎨 **主题切换**: 支持浅色/深色主题

### 技术特点
- 使用Flutter框架开发，支持iOS和Android
- Riverpod状态管理，响应式编程
- Hive本地数据库，高效数据存储
- 现代化的UI设计，流畅的用户体验

## 应用图标 🎨

应用采用了全新设计的图标，融合了以下元素：
- 📋 **闪卡元素**: 体现核心学习方式
- 🔤 **字母A**: 代表学习和知识
- 🌟 **装饰元素**: 增加视觉吸引力
- 🎨 **渐变色彩**: 现代化的视觉效果

图标设计理念：
- 主色调：蓝色渐变（#2196F3 → #1976D2）
- 强调色：金黄色（#FFD54F）
- 风格：简洁现代，符合Material Design规范

## 开发信息 👨‍💻

### 技术栈
- **框架**: Flutter 3.9+
- **语言**: Dart
- **状态管理**: Riverpod
- **本地存储**: Hive + SharedPreferences
- **语音合成**: flutter_tts
- **UI组件**: Material Design 3
